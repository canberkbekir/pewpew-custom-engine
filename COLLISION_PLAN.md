│ Voxel Collision & Splitting System - Phased Plan                                                                                                                                                              │
│                                                                                                                                                                                                               │
│ Context                                                                                                                                                                                                       │
│                                                                                                                                                                                                               │
│ The engine has voxelized meshes (bit-packed grids up to 128^3) but no physics or collision system. The goal is to add full rigid body physics via Jolt Physics, generate efficient collision shapes from      │
│ voxel grids, and implement voxel mesh splitting where collision shapes dynamically update for each fragment.                                                                                                  │

│ - DestroyBody() - removes body from Jolt, clears RuntimeBodyID                                                                                                                                                │

│ 2.1 Greedy box merging                                                                                                                                                                                        │
│                                                                                                                                                                                                               │

│                                                                                                                                                                                                               │
│ - GreedyMerge(VoxelGrid) - iterates filled voxels, extends boxes along X, Y, Z axes greedily, returns vector<MergedBox> (min/max voxel coords). Reduces ~10,000 voxels to ~500-2000 boxes.                    │
│ - CreateCompoundShape(grid, mergedBoxes) - converts merged boxes to JPH::StaticCompoundShape with one BoxShape sub-shape per merged box                                                                       │
│ - GenerateFromGrid(grid) - convenience: merge + create                                                                                                                                                        │

│ 3.2 DestructionSystem                                                                                                                                                                                         │
│                                                                                                                                                                                                               │
│ New files: CBEngine/src/CBEngine/Systems/DestructionSystem.h/.cpp                                                                                                                                             │
│                                                                                                                                                                                                               │
│ - RequestDestruction(DestructionRequest) - queues a destruction event (target entity, impact point, damage radius, force)                                                                                     │
│ - OnUpdate(Scene*, Timestep) - processes pending requests:                                                                                                                                                    │
│   a. Remove voxels from grid (sphere removal at impact point)                                                                                                                                                 │
│   b. Run connected component detection                                                                                                                                                                        │
│   c. If 1 component: update existing entity's mesh + collision shape                                                                                                                                          │
│   d. If multiple components: destroy original entity, spawn new entity per fragment with:                                                                                                                     │
│       - New VoxelRendererComponent (regenerated mesh from fragment grid)                                                                                                                                      │
│     - RigidBodyComponent (Dynamic, mass proportional to voxel count)                                                                                                                                          │
│     - ColliderComponent (VoxelCompound, auto-generates collision from fragment grid)                                                                                                                          │
│     - Inherited velocity + angular velocity from parent body                                                                                                                                                  │
│                                                                                                                                                                                                               │
│ 3.3 Collision-triggered destruction                                                                                                                                                                           │
│                                                                                                                                                                                                               │
│ In the contact listener, when impact speed exceeds a threshold, automatically queue a DestructionRequest for the impacted voxel entity.                                                                       │
│                                                                                                                                                                                                               │
│ 3.4 Scene update order (final)                                                                                                                                                                                │
│ ProcessDeferredDestroys()                                                                                                                                                                                     │
│ DestructionSystem::OnUpdate()    // split voxels, spawn fragments                                                                                                                                             │
│ PhysicsSystem::OnUpdate()        // physics step (new fragments participate)                                                                                                                                  │
│ TransformSystem::OnUpdate()      // world matrices                                                                                                                                                            │
